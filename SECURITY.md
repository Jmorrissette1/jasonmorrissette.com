# Security Policy

## Reporting a vulnerability

Please report security issues privately using GitHub's
**Security → Report a vulnerability** feature on this repository.
Do not open a public issue for security problems.

I aim to acknowledge reports within 5 business days.

## Scope

This repository powers the public website jasonmorrissette.com.
The site has no user accounts, database, or forms.
